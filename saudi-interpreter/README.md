# 사우디 통역기 (Korean ⇄ Saudi Arabic interpreter)

한국어와 사우디 아랍어를 음성으로 바로 통역해 주는 웹 앱입니다. 설치할 필요 없이 브라우저에서 열면 됩니다.

## 기능

- **양방향 음성 통역**: 🎤 버튼을 누르고 말하면 인식된 문장을 바로 통역하고 소리 내어 읽어 줍니다 (한국어 `ko-KR`, 아랍어 `ar-SA`).
- **사우디 구어체**: 나즈드(리야드)나 히자즈(제다·메카) 방언, 또는 표준 아랍어를 고를 수 있습니다.
- **한글 발음 표기**: 아랍어 번역 아래에 한글로 읽는 법을 보여 줘서 직접 따라 말할 수 있습니다.
- **문화 메모**: 뉘앙스가 중요한 경우에만 💡 짧은 설명을 붙입니다.
- **대화 맥락 반영**: 최근 대화를 함께 보내서 대명사나 생략된 말을 자연스럽게 통역합니다.
- **마주보기 모드 (⇅)**: 휴대폰을 테이블에 놓고 마주 앉으면 상대방 쪽 화면이 180° 돌아갑니다.
- **자주 쓰는 문장**: 인사, 가격 묻기, 길 묻기 등을 한 번에 누를 수 있습니다.
- 공손한 말투와 편한 말투 선택, 읽기 속도 조절, 🔊 다시 듣기를 지원합니다.

## 실행 방법

정적 파일만 있으므로 아무 웹 서버로나 열면 됩니다. 마이크를 쓰려면 `https://` 또는 `localhost`에서 열어야 합니다.

```bash
cd saudi-interpreter
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

GitHub Pages에 올리면 휴대폰에서도 바로 쓸 수 있습니다.

처음 열면 ⚙ 설정에 [Anthropic API 키](https://console.anthropic.com/)를 넣으세요. 키는 이 브라우저의 localStorage에만 저장되고 `api.anthropic.com`으로만 전송됩니다. 개인용으로 쓰는 앱이니 키가 들어간 상태로 다른 사람과 기기를 같이 쓰지 마세요.

## 브라우저 지원

| 기능 | Chrome / Edge | Safari (iOS·macOS) | Firefox |
|---|---|---|---|
| 음성 인식 | ✅ | ✅ | ❌ (텍스트 입력만) |
| 음성 출력 | ✅ | ✅ | ✅ |

아랍어로 읽어 주려면 기기에 아랍어 음성이 설치되어 있어야 합니다. iOS에서는 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성에서 추가할 수 있습니다.

## 구성

- `index.html`: 화면 구성
- `style.css`: 스타일 (다크 모드 지원)
- `app.js`: 음성 인식(Web Speech API), Claude API로 통역, 음성 출력(speechSynthesis)

기본 모델은 Claude Opus 5.5이고, 설정에서 Sonnet 5.5나 Haiku 5.5(가장 빠르고 저렴)로 바꿀 수 있습니다.
