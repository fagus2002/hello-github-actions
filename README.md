## 스마트팜 환경 교실 (`smartfarm-academy/`)

스마트팜 환경설정을 기초부터 배우는 단일 HTML 학습 앱입니다. `smartfarm-academy/index.html`을 브라우저로 열면 바로 실행됩니다.

- **학습**: 환경제어 구조, 온도, 습도·VPD, CO₂ 시비, 광(PPFD·DLI), 양액(EC·pH), 제어 로직(불감대·비례대·우선순위), 실전 설정 순서 등 8개 강의와 강의별 확인 문제
- **환경제어 시뮬레이터**: 작물(토마토·딸기·파프리카·상추)과 주·야간을 고르고 센서값을 바꾸면 VPD·DLI 계산, 적합도 점수, 구동기(난방·환기·포그·차광·CO₂·보광·양액) 반응과 조치 안내, VPD 지도 표시
- **확인 퀴즈**와 **용어집**, 학습 진도는 브라우저에 저장

설정값은 학습용 일반 기준이므로 실제 재배 시 품종·지역 권장값을 함께 확인하세요.
