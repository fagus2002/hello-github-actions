# 오이 양액재배 진단

브라우저에서 바로 여는 단일 HTML 앱입니다. `index.html`을 열면 됩니다(설치 불필요).

## 입력 항목
- **재배 조건**: 생육 단계(육묘기 / 정식~착과 / 수확기), 계절, 재배 방식(암면·코이어 비순환, NFT·DFT 순환식)
- **급액 양액**: EC, pH, 양액 온도, 용존산소
- **배액·근권**: 배액 EC·pH, 1주당 급액량·배액량(배액률 자동 계산), 근권 온도, (순환식) 양액 교체 경과일
- **온실 환경**: 주·야간 기온, 습도(VPD 자동 계산), CO₂, 누적 일사량(일사 대비 급액량 판정)
- **생육 조사**: 주간 생장 길이, 줄기 굵기, 착과 수
- **관찰 증상** 11종: Mg·Fe·Ca·N·K 결핍, 시들음, 뿌리썩음, 기형과, 순멎이, 과번무, 잎 병해

## 진단 방식
- 항목마다 조건별 기준 범위와 비교해 적정 / 주의 / 위험으로 판정하고 원인과 조치를 제시합니다.
- 증상은 측정값과 교차 확인합니다(예: 새 잎 황화 + 배액 pH 6.5 초과 → 철 결핍 가능성 강조).
- 측정 항목 평균 점수에서 증상 감점을 빼 0–100점으로 종합하고, 양액·근권·환경·생육 영역별 점수를 보여줍니다.
- 진단 기록은 브라우저(localStorage)에 저장되며, 결과를 텍스트로 복사할 수 있습니다.

기준 범위는 국내 오이 시설 양액재배 일반 권장치를 단순화한 참고값입니다. 품종과 배양액 처방에 맞게 `targets()` 함수의 값을 조정하세요.
